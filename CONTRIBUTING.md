# Contributing to your-server-board

This is a small personal fork of [Homepage](https://github.com/gethomepage/homepage),
not a large community project — there's no formal governance process, bot
triage, or contributor ladder here.

- **Bugs or feature ideas about this fork's Proxmox/disk/backup features:**
  [open an issue](https://github.com/pavel-z-ostravy/your-server-board/issues).
  Include what you ran, what you expected, and what actually happened.
- **Pull requests are welcome.** By submitting one you agree it's licensed
  under this project's GPL-3.0 license, same as the rest of the repo.
- **AI-assisted contributions are fine — just say so.** If a significant
  portion of a PR was generated with AI assistance, mention that in the PR
  description.
- **Anything about the underlying Homepage config engine, widgets, or
  themes** (not specific to this fork's additions) is better raised
  upstream — see [gethomepage/homepage's own contributing guide](https://github.com/gethomepage/homepage/blob/dev/CONTRIBUTING.md)
  and [development docs](https://gethomepage.dev/widgets/authoring/getting-started/).
